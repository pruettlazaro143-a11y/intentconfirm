## 6. Bob 默认值与需求简报

采用默认：标记完成后保留在列表（可查历史），标注"已完成"样式与进行中的区分。这是可逆的，以后删掉也容易。

**需求简报**

- 目标：个人阅读进度追踪工具，给自己用
- 核心功能：添加书/课/资料 → 记录当前章节和完成百分比 → 更新进度 → 标记完成
- 数据：localStorage，无后端，无登录
- 界面：单页 HTML，双击即开
- 完成后可看到：进行中的列表（按进度排序）+ 已完成的列表
- 排除：多用户、账号、付费、分享、导入导出（第一版不做）
- 假设：完成 = 标记，保留历史；样式区分进行中 vs 完成
