## 浏览器实际覆盖

1. 直接通过 file:// 打开整个项目，依次检查输入、澄清、确认页面。
2. 使用合成需求“给自己用的 AI 雅思网站，不要登录，记录每日练习，预算3000元”。
3. 点击原文候选确认，验证不擅自增加支付限制，原文依据保留。
4. 补充目标、交付深度、AI 作用和成功标准，确认 v1。
5. 实际触发并读取 Markdown/JSON 下载文件，核对 AI 作用、排除项与预算。
6. 从确认页修改已确认目标，检查关联项变 stale，受众与历史保持。
7. 口语切换作文，录音问题不再作为当前范围；其旧答案标记失效。
8. AI 作用选择“不确定”后，确认按钮不可用；重新明确后保存 v2。
9. 刷新恢复版本；v1 快照仍保留原始细节。
10. 陌生输入显示覆盖限制；自定义 HTML 片段仅以文本展示。
11. 未知高优先级问题不阻塞后续问题的展示。
12. 390×844 视口下，输入、澄清、确认页面无横向溢出。

## DeepSeek 路径验证

1. 模型添加确认字段不能代替用户同意；必填未知与待确认候选阻止确认。
2. 伪造证据、未确认来源、依赖循环、静默改写问题定义均拒绝采用。
3. 修改回答后就绪建议过期，依赖候选失效；旧来源不符时不能重新采纳。
4. 迟到的接口结果不能覆盖新输入；历史版本保持不变。
5. 使用注入 fetch 检查真实适配器的官方 URL、Bearer、JSON 模式和 thinking 参数。
6. 空响应、输出截断、非法 JSON、缺少密钥、401 均明确失败；错误不回显密钥。
7. 本机 HTTP 服务拒绝跨来源调用，拒绝读取 .env 和非公开文件；无密钥时不调用模型。
8. 真实浏览器检验：首次分析、确认候选、点选不发请求、重新分析、确认与 JSON 下载。
9. 模拟模型错误与重试时保持用户回答；模拟 ready=true 仍不能绕过未知必填项。
10. 模式切换和刷新保留独立草稿，390px下三步均无横向溢出，没有未捕获页面错误。

**模拟响应预先写在测试中，不能当作模型实际生成效果的证据。**
